# IdolChat.app Assets: AI Character Images and Avatars

Public image assets for **[IdolChat.app](https://idolchat.app)**, the free AI character chat and card-collection game: character art, avatars and shared UI images.

[![Website](https://img.shields.io/badge/idolchat.app-live-8B5CF6?style=for-the-badge)](https://idolchat.app)

## What is IdolChat?

IdolChat lets you create unlimited custom AI characters, chat with anime legends, movie icons and gaming champions, claim rare digital cards in daily drops and build your own collection.

## What's in this repo

| Folder | Contents |
|---|---|
| `characters/` | 130+ character sets, one folder per character or franchise (anime, film, sport, music and more) |
| `avatars/` | User and character avatars (`.webp`) |
| `assets/` | Shared UI images used by the app |

Please don't hotlink these assets from other products. Character artwork belongs to its respective owners.
